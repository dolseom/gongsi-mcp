# 1. 서론과 방법

## 1.1 조사 질문

dart-ftc-mcp는 2026-07-30 실무 피드백을 반영해 3축 구조로 방향을 재정의했다:

- **축 1 범용**: 선례 검색·원문 읽기·문안 참고·초안 (최우선 — 매일 쓰는 기능)
- **축 2 특화**: 공정위 기업집단 공시 판정·감사 (유일무이 영역)
- **축 3 기본기**: 재무제표·기업개황·정기보고서 (당연한 기대치)

이 재정의가 실제 공시담당자·IR담당자·공정거래팀 실무자의 니즈와 부합하는지를 외부 증거로 검증하는 것이 본 조사의 목적이다. 하위 질문 4가지:

1. 공정위 기업집단 공시 컴플라이언스에서 실무자가 가장 힘들어하는 것은 무엇인가
2. DART 공시 작성 시 선례 검색·타사 문안 참고는 실재하는 관행인가, 어떻게 수행되는가
3. 공시 기한·과태료 리스크는 어떻게 관리되고 있는가
4. 기존 도구(DART 편집기·상용 서비스·사내 시스템)는 무엇을 채우고 무엇을 비워두는가

## 1.2 방법

- **조사 에이전트 5개** 병렬 투입 (S1 공정위 컴플라이언스 / S2 작성 관행 / S3 기한·과태료 관리 / S4 도구 생태계 / S5 담당자 직무 실태)
- **소스 155건** 수집 — 공정위 보도자료 원문 PDF(직접 다운로드·추출), FKI 건의서 원문 PDF, KRX 해설서, 로펌 뉴스레터, 언론, 실무자 블로그·커뮤니티
- **검증 게이트**: 핵심 주장 16건을 claim ledger로 작성, high-risk 13건 전건 반증 검색(counter-search) 수행 후 결정론적 게이트(`validate_ledger.py`) 통과 — verified 15 / unresolved 1 / refuted 0
- 소스 등급: A(정부/공식) · B(협회·로펌) · C(주요 언론) · D(블로그·보도자료) · E(커뮤니티)

## 1.3 조사의 한계 (미리 밝힘)

- **정량 실태조사 부재**: 협회(IR협의회·상장협·코스닥협회)의 담당자 설문 원문은 웹에서 확보 불가(회원 전용·비색인). 겸직 비율·인력 규모·업무시간의 통계 수치는 이 보고서에 없다.
- **커뮤니티 본문 미확인**: 최대 실무자 커뮤니티(네이버 카페 BestIR, 약 1만 명)는 로그인 장벽으로 게시글 제목만 확보.
- **부재 증명 불가**: "공시담당자 타겟 상용 제품이 없다"는 주장은 2회 독립 검색에서 미발견이라는 것이지 부재의 증명이 아니다(부록 Unresolved 참조).
- 본문에서 [clm_NNN]은 검증 통과 주장의 원장 ID다 (`artifacts/claim_ledger.jsonl`).
