# 4. 도구 생태계의 공백 — 무엇이 있고 무엇이 비어 있는가

## 4.1 선례 참고는 표준 관행, 도구는 Ctrl+F [clm_009]

타사 사례 벤치마킹은 공시 실무 입문 단계에서부터 가르치는 **명시적 권장 관행**이다("동종 업계 상장사들이 어떻게 공시했는지 DART에서 검색해 보세요"). 금감원 스스로 '기업공시 길라잡이'에서 항목별 **모범사례**를 제공한다 — 규제 당국이 "기재례를 보고 따라 쓰는" 학습 모델을 공인한 것이다.

실제 수행 절차(현직 회계사의 1인칭 기록):

1. 새로 써야 할 항목 발생 (신규 제도, 처음 겪는 거래 유형)
2. DART 공시통합검색에서 검색구분을 "회사명" → **"본문내용"으로 수동 변경**
3. 키워드 + 공시유형 + 기간 조회 → 수십~수백 건 목록
4. 후보 문서를 **하나씩 클릭해서 열고**
5. **Ctrl+F로 해당 항목을 찾아** 읽음

DART는 본문 전문 인덱스와 불리언 연산(AND/OR/NOT/EXACT)을 공식 지원한다. 즉 **검색 자체는 이미 존재한다. 병목은 4~5단계 — 검색 결과에서 원하는 문안 조각까지 도달하는 마지막 구간**이다. "Ctrl+F 요령"이 실무 팁으로 공유되어야 할 만큼 이 구간의 도구 지원이 없다.

**제품 함의**: `find_precedents`의 차별점은 "더 좋은 검색"이 아니라 **"검색 결과에서 문안 조각을 꺼내주는 것"**이다. 원문 파서(`src/parsers/document.ts`)가 정확히 이 구간의 자산이며, "자금차입 510건 → 타사 기재(MOR+1.49%) 추출" 프로토타입이 이미 그 방향이다.

## 4.2 공식 도구는 '제출'까지만 담당한다

DART 편집기는 2024년 3월 대규모 개선을 받았지만(서식 유지 붙여넣기, 자동 변환, 맞춤법, 표 자동 합계 — 뒤집어 읽으면 그전까지의 불편 목록), 여전히 **폐쇄형 전용 포맷(.dsd) + 전용 데스크톱 프로그램** 구조다. 이 도구들은 "양식을 올바르게 채워 제출"까지를 담당하며, **"이 거래가 공시 대상인가", "기한이 언제인가", "타사는 뭐라고 썼나"의 판단·조회 영역은 비어 있다**. 공정위 기업집단 공시는 제출 경로 자체가 별도(기업집단포털)라 실무자는 두 체계를 병행한다.

## 4.3 상용 서비스는 전부 '읽는 쪽'을 향한다 [clm_010 — 미확정, 강한 정황]

확인된 상용 서비스(딥서치, 에프앤가이드/와이즈리포트, DartPoint AI, 미래에셋 AI 공시요약, 삼일아이닷컴, 로앤비)는 전부 **투자자·분석가·법률가 타겟**이다. 공시담당자(쓰는 쪽)를 정면 타겟한 제품은 본 조사(에이전트 조사 + 반증 재검색)에서 발견되지 않았고, 공정위 기업집단 공시를 다루는 서비스도 확인되지 않았다.

⚠️ **이 주장은 검증 게이트에서 '미확정'이다** — 근거가 전부 D등급(서비스 소개 페이지)이고 부재의 증명은 불가능하다. B2B 실무 솔루션은 웹 노출이 적고, 로펌·회계법인이 자문(사람) 형태로 이 수요를 흡수하고 있을 가능성이 크다. "경쟁 제품이 없다"가 아니라 "**경쟁 제품이 웹에서 보이지 않는다**"까지만 말할 수 있다.

## 4.4 사내 관리는 시스템이 아니라 문서 체계다

대기업 내부거래 관리의 공개된 실체는 CP(공정거래 자율준수 프로그램) 편람 + 내부거래위원회다. 그룹웨어·전자결재와 공시 기한 관리가 연동된 IT 시스템 사례는 웹에서 확인되지 않았으며, 위반 원인으로 "내부 승인 절차와 공시 기한 간 충돌"이 지목되는 것은 **결재 시스템과 공시 기한이 연결돼 있지 않다**는 정황 증거로 읽힌다(해석). 내부거래위원회는 수시 개최라 의결일이 사전에 예측되지 않고, 기한 카운트다운은 위원회 개최 후에야 시작된다.

## 4.5 AI의 현재 위치: '초안까지, 판단은 사람' [clm_016]

작성 측 공시 워크플로에 공식 투입된 AI는 거래소-네이버클라우드 **공시 전용 AI 번역기**(영문공시 초벌 번역) 단 하나다. 금융분야 AI 가이드라인(2026-06-22 시행)은 '보조수단성'을 7대 원칙으로 명문화했다. 클라우드 SaaS는 기밀유출 우려(삼성전자 2023년 ChatGPT 금지 사례)라는 구조적 장벽을 안고 있다.

**제품 함의 (추론)**: ① "자동 제출은 만들지 않는다 — 초안까지만"이라는 프로젝트 원칙은 규제 프레임과 정확히 합치한다. ② 로컬 실행 + 사용자 API 키 + 공개 데이터만 조회하는 MCP 아키텍처는 기밀유지 장벽을 우회하는 형태다 — 단 이는 검증된 시장 반응이 아니라 조사 결과로부터의 추론이다.
