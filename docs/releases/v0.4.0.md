# gongsi-mcp 0.4.0

작성 2026-10-04. 실행 중인 버전은 `server_info` 의 `version` 으로 확인하세요.

## 요약

**OpenDART 송신 제어와 "확인 못 한 것을 확인한 것처럼" 보이던 결론을 고친 릴리스입니다. 올리는 것을 권합니다.**
도구 수(17개)·Node.js 하한(22.13+)은 그대로입니다. 출력에는 필드가 **추가**만 됐고 기존 필드는 그대로입니다.
기본 동시성이 10 → 4 로 바뀌었습니다(`GONGSI_CONCURRENCY` 로 되돌릴 수 있음).

## 바뀐 것

### 1. OpenDART 송신 제어

OpenDART 과호출 차단은 IP 단위라, 같은 공인 IP(사내망)를 쓰는 사람 전원이 함께 막힙니다. 이를 막기 위해:

- 프로세스 전역 **송신 대기열** — 앞 요청이 실제로 시작된 뒤 200ms(`GONGSI_DART_MIN_INTERVAL_MS`) 간격으로 보냅니다.
- 응답 없는 접속 실패가 연속 4회면 60초 동안 호출을 멈추고 `upstream_unavailable` 로 알립니다(재시도 없음).
- 429 의 `Retry-After` 를 프로세스 전체에 적용합니다. 10초를 넘으면 기다리지 않고 실패로 알립니다.
- 기본 동시성 10 → 4. 실측(2026-10-04): 현재 호출 지연(0.2~0.3초)에서는 송신 간격이 속도를 정해
  동시성 1·2·4·10 의 수집 시간이 같았습니다(전체시장 2주 7,134건 17.4초).

### 2. 조건이 남은 결론은 조건형으로 — `check_disclosure_duty`

집단 소속·상대방 요건이 `[미확인]` 인데도 "공시 대상입니다 … 이사회 사전 의결이 필요합니다"로 단정하던 것을
**"[미확인] N개가 모두 충족되면 …"** 으로 바꿨습니다. summary·`review.answer`·evidence(지연·과태료·자진시정)·
"즉시 공시" 안내에 같은 조건이 붙습니다. `verdict` 값은 그대로입니다.

- 공익법인(공정거래법 제29조제1항 원문)·약관에 의한 금융거래에도 적용 요건 체크리스트를 붙였습니다.
- 당일 합산 금액으로 판정한 건에서 체크리스트가 합산 전 금액을 써 `required` 와 `[불충족]` 이 함께 나오던 모순을 고쳤습니다.

### 3. 점검 도구 — 확인 못 한 회사를 따로 보고

- `audit_group_disclosures`·`audit_periodic_disclosures` 에 50초 시간 예산을 둡니다. 예산이 다 되면 새 조회를 시작하지 않고
  남은 대상을 `not_started_time_budget` / `not_checked` 로 보고합니다(60초 연결 끊김으로 결과 전체를 잃지 않도록).
- ★ **`audit_periodic_disclosures` 에서 공시 목록 조회에 실패한 회사가 `not_filed_candidates`(미제출 후보)에 들어가던 결함**을 고쳤습니다.
  네트워크 오류·시간 초과·시간 예산 소진으로 수집이 불완전한 회사·유형은 `not_checked`·`list_errors` 로 분리합니다.
  불완전 수집에서 찾은 접수가 기한 뒤면 더 이른 접수가 빠졌을 수 있어 지연 후보로 단정하지 않습니다.
- `audit_periodic_disclosures` 의 "모집단 전부가 한 건도 내지 않음(🚨 `likely_out_of_scope`)"은 실제로 조회된 회사만으로 판단합니다.
- `audit_group_disclosures` 는 수집에 실패한 기간을 `coverage.list_complete`·`coverage.list_gaps` 와 notes 에 구간째로 알립니다
  (그 기간의 접수분은 판정 대상에 오르지 않으므로 "지연 0건"을 "지연 없음"으로 읽지 않도록).
- 원문 다운로드 분할 제안(`range_too_large`)의 구간이 이제 빈틈없이 이어집니다.
- 기간 검색이 시간 초과로 중단되면 진행 중이던 페이지 요청까지 취소합니다(결과에 쓰이지 않을 호출이 송신 대기열을 차지하지 않도록).

### 4. 공휴일·기한 경고

- 공휴일 데이터 경고를 기한 연도만이 아니라 **기산일~기한 사이 모든 연도**로 검사합니다
  (예: 2025-12-23 비상장 → 경고 없이 2026-01-02 로 계산되던 사례. 정답은 01-05).
- 자진시정 기간(기한 익일부터 10영업일)에도 같은 경고를 붙입니다. `calc_business_days` 는 중간 연도도 검사합니다.
- 점검 도구가 기한 경고를 `deadline_warnings` 와 상단 notes 로 전달합니다.
- 과태료 산정에서 위반 이력을 입력하지 않으면 0회로 계산했다고 밝힙니다.

### 5. 기간이 너무 넓을 때 — `range_too_large`

나눠서 조회할 구간을 최대 6개만 제안하고, 전체 구간 수(`totalSplits`)와 제안 뒤 남은 범위(`remainingRange`)를 함께 줍니다.
